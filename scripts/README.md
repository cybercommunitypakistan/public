# Cleanup Scripts

These scripts help clean up Prisma-related files after migrating to Mongoose.

## Usage

### Unix/Linux/Mac

```bash
./scripts/cleanup-prisma.sh
```

### Windows

```bash
scripts\cleanup-prisma.bat
```

## What Gets Cleaned Up

1. **Generated Prisma Client** (`lib/generated/prisma/`)
   - All TypeScript types and client code generated by Prisma
   - Can be safely deleted since we're using Mongoose now

2. **Generated Directory** (`lib/generated/`)
   - Parent directory, removed if empty after Prisma cleanup

3. **Prisma Migrations** (`prisma/migrations/`)
   - All migration files created by Prisma
   - Not needed with Mongoose (schema is defined in code)

4. **Node Modules** (`node_modules/`)
   - Removed to ensure clean install of new dependencies
   - Eliminates any cached Prisma artifacts

5. **Lock Files** (`pnpm-lock.yaml`, `package-lock.json`)
   - Regenerated with clean dependency tree
   - Ensures no stale dependency references

## After Running

The script will prompt you with next steps:

1. **Install dependencies**
   ```bash
   pnpm install
   ```

2. **Update environment variables**
   - Copy `.env.example` to `.env`
   - Add your `MONGODB_URI`

3. **Seed the database**
   ```bash
   pnpm db:seed
   ```

4. **Start development server**
   ```bash
   pnpm dev
   ```

## Manual Cleanup (Alternative)

If you prefer to clean up manually:

```bash
# Remove generated Prisma files
rm -rf lib/generated/prisma
rm -rf prisma/migrations

# Clean install
rm -rf node_modules
rm pnpm-lock.yaml

# Reinstall
pnpm install
```

## Troubleshooting

### Script Won't Run (Unix/Linux/Mac)

Make the script executable:
```bash
chmod +x scripts/cleanup-prisma.sh
```

### Permission Errors (Windows)

Run Command Prompt or PowerShell as Administrator.

### Files Still Exist

Some files may be in use. Close your IDE/editor and try again.

## Safe to Run Multiple Times

These scripts are idempotent - safe to run multiple times. If a file/folder doesn't exist, it's simply skipped.
